# Русский интерфейс: реализация и Windows-проверка

Дата: 2026-11-02, Asia/Yekaterinburg.
Статус: интерфейс реализован; Windows-переключение всех трёх окон и трея проверено.
Область: [план локализации](../plans/2026-11-02-russian-ui-localization.md),
[описание устройства](../localization.md).

## Реализованное поведение

Русский по умолчанию, переключение на English в настройках и при первом запуске.
Переведены основные экраны, popup, recordbar, native-заголовки/трей, подписи
доступности, файловые диалоги, сообщения и статусы. Каталоги и кириллические
шрифты входят в сборку. Даты, числа, размеры и plural-формы следуют языку UI.

Язык хранится отдельным ключом `ui_locale`. Обычное сохранение `Settings`
не может его откатить. Событие доставляется всем WebView, включая скрытые;
более новое событие защищено от позднего чтения или ответа сохранения.
Native-пункты трея обновляются вместе в главном потоке, с актуальным состоянием.

Команды и сообщения Bazza используют стабильные коды, параметры и исходные
технические подробности. Исторические строковые ошибки продолжают отображаться.
Системные метки участников переводятся только для показа; rename/merge и
экспорт сохраняют исходные значения. Пользовательские шаблоны, промпты,
транскрипты, саммари и имена не переводятся.

## Программные проверки

- `pnpm typecheck` — успешно.
- `pnpm test` — **59 тестов, 17 файлов**, успешно. Включены полнота/параметры
  каталогов, русские plural-формы, fallback, межоконная синхронизация и гонки,
  сохранность STT/capture-настроек, переименование/объединение участников,
  обновление уже видимых ошибок и элементов управления.
- `pnpm build` — успешно. Vite предупреждает о JS chunk больше 500 kB;
  это предупреждение размера, не ошибка сборки.
- `cargo check -p bazza --release --tests --offline` — успешно.
- `cargo test -p bazza --release --lib --offline` — первоначально 27 passed,
  на объединённом snapshot **33 passed, 1 ignored**.
  Проверены отдельное хранение языка, отказ сохранения, ошибочный/отсутствующий
  ключ, состояния трея, коды сообщений и безопасность переноса библиотеки.
  Ignored-тест импорта с FFmpeg имеет собственные требования к запуску.
- `cargo test -p bazza-store --release --offline` — первоначально 29 passed,
  после изменений владельца голосов **37 passed**. Проверки включают snapshot
  при занятом WAL reader; результаты переданы владельцам соседних задач.
- `cargo build --release -p bazza --features tauri/custom-protocol --locked --offline`
  — успешно, обычный bundle config, подготовленный новый sidecar включён.
- `cargo clippy --release -p bazza --all-targets --features tauri/custom-protocol --locked --offline -- -D warnings`
  — успешно, обычный config без исключения ресурсов.

Команды JavaScript проверялись через pnpm 10 / Node 24. Rust использовал локальную
MSVC/LLVM-среду; runtime DLL находились в `src-tauri/resources`.
Параллельные задачи переименования и восстановления записи владели своими
исходниками; Cargo и runtime запускались по согласованной очереди.

## Ограничения

- macOS runtime и упакованный `.app` не проверены на этом Windows-компьютере.
  Русские/английские ресурсы описаний разрешений добавлены; язык системного
  запроса определяется macOS.
- Матрица масштабирования 125/150/200%, обе темы на каждой платформе и полный
  прогон с экранным диктором остаются отдельной визуальной приёмкой.
- Активная/приостановленная запись проверена компонентными сценариями и
  комбинациями состояний трея в Rust; этот native-прогон показывал панель
  при `recording_status=idle` и не является аппаратной приёмкой записи.
- Сайт, установщик, содержимое экспортированных документов, страница получателя
  по ссылке и новые автоматические названия встреч остаются отдельным объёмом.
