## Способ проверки

Локальный harness вызывает зарегистрированные Tauri-команды через WebView2 CDP
на loopback. Запись, настройки и импорт выполняются напрямую через IPC;
playback и seek проверяются в настоящем WebView приложения через DOM/media API.
Физический указатель мыши для этих автопрогонов не используется.

До запуска проверены указатель библиотеки, `data_info`, idle recorder, хеш EXE,
отсутствие моделей и включённых внешних обработчиков. Для записи выбран виртуальный
CABLE Output вместо комнатного микрофона. Источник видео — второй монитор:
DISPLAY2, 1920×1080, физическое положение −1920/0, подтверждённое native monitor API.
Плеер показывает только существующий искусственный flash/tone-ролик.

## SRT и WebVTT — `cf910fca` / `d3737b2a`

Оба формата импортированы командой `import_recording` с `transcriptPath`, через
тот же native importer, который вызывает Library. Каждый создал отдельную Ready
встречу длительностью 150,016 с с видео и тремя искусственными репликами.

Текст, начало/конец каждой реплики и `clean_text = null` точно совпали с fixtures.
SRT не создал speaker labels; WebVTT сохранил три ожидаемых имени из voice spans.
Саммари отсутствует, глобальная база голосов осталась пустой. Распознавание,
агенты и внешние провайдеры этим путём импорта не запускаются.

В настоящем WebView проверены отображаемый текст и имена, декодирование видео,
muted playback с продвижением времени/кадров, seek на 2/20/40 с через media API
и через обработчик каждой строки транскрипта. Затем Hark полностью перезапущен:
обе встречи, точные данные, playback и оба способа seek проверены повторно.
Оба автоматических запуска завершились успешно.

## Воспроизведение и оставшиеся ограничения

Локальные скрипты хранятся в игнорируемой области `.git/local-tools`:
`run-720-automated.mjs <новое-имя-прогона>`, `analyze-720-automated.py <meeting-id>`,
`verify-recording-player.mjs <meeting-id>` и `run-import-automated.mjs`
с последующим `--verify-existing` после перезапуска приложения.
Они требуют подготовленного локального стенда и CDP; это не переносимые CI-тесты.
JSON-доказательства — `automated-720-20261102-b`, `automated-720-b-analysis`,
`automated-imports/import-results.json` и `automated-product/player-*.json`
в игнорируемой контрольной области. Медиа и runtime/session state не коммитятся.

30 FPS/1080 и микрофон NVIDIA Broadcast восстановлены, активной записи нет.
Тестовый экземпляр Hark завершён, локальный CDP listener закрыт.
Субъективное качество 720p, слышимые артефакты и нагрузка этим прогоном не приняты.
Native диалоги выбора файлов обойдены IPC и остаются отдельной UI-проверкой.
Физическая потеря endpoint, получасовой стресс, `.hark` между двумя библиотеками,
модели, внешние интеграции и macOS не покрыты.

Позднее [`.hark` между двумя Windows-библиотеками проверен отдельно](2026-11-02-bundle-runtime-acceptance.md),
включая media/metadata, отрицательные случаи, rollback/retry/duplicate и native
playback/restart. Остальные ограничения этого первоначального прогона сохраняются.
