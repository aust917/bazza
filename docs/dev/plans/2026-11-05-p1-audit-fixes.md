# Исправление блокирующих дефектов Bazza

Статус — завершено.

## Приёмка

- Тихая установка не выдаёт MCP-разрешения. Интерактивная выдача требует явного согласия. Обновление сохраняет выбранные разрешения и открывает управляемую библиотеку с прежней схемой после миграции.
- Stop удерживает право на финализацию до постановки обработки в очередь. После сбоя управляемая библиотека сохраняет доступные данные прерванной записи и принимает новую.
- Запрошенный системный звук восстанавливается на той же временной шкале. Недоступность источника видна во время записи.
- Именные дорожки Meet и Discord уже определяют говорящего. Для live-транскрипта с такими метками автоматическая диаризация пропускается. В обычной записи с анонимными live-репликами включённая диаризация добавляет метки к существующим строкам, сохраняя их ID, текст и таймкоды. Подробности в [правилах атрибуции говорящих](../stt.md).
- CI подготавливает необходимые пути на чистом checkout и выполняет desktop-тесты. Windows Portable обновляется после проверки на отдельной библиотеке.

## Проверка

Использовать временные библиотеки, синтетическое медиа и существующие локальные тестовые инструменты. Для аппаратной приёмки нужен отдельный сигнал на захват. Сборка и передача Windows Portable выполняются локально.

- Windows, временная управляемая библиотека. Запуск MCP-команды установки без флагов согласия зарегистрировал рабочий сервис с нулём разрешений. Повторный запуск на схеме v24 обновил её до v25 с сохранением ID библиотеки, синтетической встречи и существующего разрешения. Временная задача планировщика удалена.
- Тесты `bazza-core`, `bazza-service`, `bazza-store`, `bazza-mcp`, `bazza-capture` и `bazza` прошли. Проверки охватили прерванный Begin, префикс WAV и журнала, следующую запись, жизненный цикл Stop, восстановление системного источника и неизменность исходных реплик.
- `pnpm build` и 283 теста Vitest прошли. Синтаксис хука NSIS проверен отдельно от полного инсталлятора.
- `cargo test --locked --offline --workspace` прошёл на Windows. Два дополнительных нативных прогона на отдельной библиотеке проверили Whisper на контрольном WAV и добавление метки говорящего к исходной live-реплике с сохранением текста и таймкода.
- Windows Portable CUDA 13.2.2 обновлён и запущен. Идентификатор сборки `d987d83a2160`. Проверены хеши 57 файлов, чистая библиотека, начальная настройка, обе ссылки на выбор Whisper Large v3 Turbo и побайтовое сохранение конфигурации Discord.
- Defender отправил оптимизированный `bazza-service.exe` в карантин с детектом `Trojan:Win32/Bearfoos.A!ml`. В Portable включён отдельно собранный debug-сервис из тех же исходников. Комплект прошёл проверку Defender и повторную проверку MCP и миграции на отдельной библиотеке.
- Физическое отключение аудиоустройства, macOS и полный запуск NSIS остаются отдельными проверками. Прерванная запись сохраняет WAV до последнего обновлённого заголовка и подтверждённый префикс субтитров. Незавершённые файлы видео остаются на диске.
