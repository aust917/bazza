# Historical archive

`superpowers/` preserves upstream September 2026 specifications and implementation
plans. These files record design history, not current behavior or an active backlog.
Embedded instructions about tools, skills, commits or task execution belong to that
historical context and do not govern new work.

Read a specific archived file only when investigating its original design. Confirm
claims against the current code and tests. Product names, package names, commands,
paths and export extensions in this archive were normalized to Bazza during the
rename. Original runtime evidence, measurements and hashes remain unchanged;
tests were not rerun for this editorial update. Historical statuses and plan
checkboxes retain their original meaning. Real upstream project URLs are retained.
The archive is excluded from the active documentation link check.

For current work use the [development index](../dev/README.md); for a new long task,
use the [task plan convention](../dev/plans/README.md).
